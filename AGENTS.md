# Repository Guidelines

## Project Structure & Module Organization
- `src/` contains the TypeScript source.
- `src/index.ts` wires the MCP server and registers tools.
- `src/tools/<area>/` groups tool implementations by feature (simulator, screenshot, ui, etc.).
- `src/types/` holds shared types and constants.
- `src/utils/` contains shared helpers.
- `tests/` holds Vitest unit tests (`*.test.ts`).
- `examples/` contains Markdown usage workflows.
- `dist/` is build output (generated by `npm run build`).

## Build, Test, and Development Commands
- `npm install` installs dependencies.
- `npm run dev` builds in watch mode via tsup.
- `npm run build` produces `dist/` for publishing.
- `npm run start` runs the built server from `dist/index.js`.
- `npm run typecheck` runs `tsc --noEmit` with strict settings.
- `npm run lint` runs ESLint over `src/`.
- `npm run test` runs the Vitest suite once.
- `npm run test:watch` runs tests in watch mode.
- `npm run test:coverage` generates V8 coverage reports.

## Coding Style & Naming Conventions
- TypeScript, ES modules, Node 18+.
- Use 2-space indentation and double quotes, matching existing files.
- Keep relative import specifiers with `.js` extensions (ESM output expects them).
- Tool folders are lowercase (e.g., `src/tools/screenshot`).
- Tests use the `.test.ts` suffix under `tests/`.

## Testing Guidelines
- Framework: Vitest (`tests/**/*.test.ts`).
- Coverage includes `src/**/*.ts` and excludes `src/index.ts`.
- Prefer unit tests alongside new tool logic or utilities.

## Commit & Pull Request Guidelines
- Commit messages mostly follow Conventional Commits (`feat:`, `fix:`, `chore:`); use that style when possible.
- PRs should include a short summary, testing notes (e.g., `npm run test`), and any simulator/version assumptions.
- Include before/after screenshots or logs if changes affect simulator output or image processing.

## Configuration Notes
- Requires macOS with Xcode and iOS Simulator runtimes.
- CLI entrypoint is `dist/index.js` and is built via tsup; avoid committing `dist/` changes unless releasing.
